# Правила проекта и рабочего процесса

## Рабочий процесс Git (Git Workflow)
- **Обязательное согласование изменений перед коммитом и пушем**:
  Перед выполнением команд `git commit` и `git push` агент **ОБЯЗАН**:
  1. Вывести подробное описание сделанных изменений и `git diff`.
  2. Объяснить, какие файлы затронуты и с какой целью.
  3. Дождаться явного подтверждения/одобрения пользователя перед тем, как фиксировать коммит и отправлять изменения в удаленный репозиторий.
- Запрещено выполнять `git commit` и `git push` автоматически без предварительного согласования с пользователем.
